openface_study.ipynb= processes and analyzes facial analysis data from OpenFace, specifically for thumbnails. It reads multiple CSV files generated by OpenFace, merges them, cleans the data, and performs exploratory data analysis to prepare the dataset for further research.

/newline
kmodes.ipynb= This project applies k-Modes clustering to categorical data. k-Modes is an unsupervised machine learning algorithm that extends k-Means for categorical variables by using the mode instead of the mean for centroid updates.

note: install dependencies pip install pandas kmodes matplotlib seaborn scikit-learn
